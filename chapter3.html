Section B — True / False (10)

16. 0.8 is greater than 0.75.

Correct Answer: True

17. 3.40 and 3.4 represent the same number.

Correct Answer: True

18. In 5.027, the digit 2 represents two tenths.

Correct Answer: False. The digit 2 is in the hundredths place.

19. 0.09 is greater than 0.1.

Correct Answer: False. 0.1 = 0.10, which is greater than 0.09.

20. Adding zeroes to the right of a decimal does not change its value.

Correct Answer: True

21. 4.999 is greater than 5.

Correct Answer: False. 4.999 is less than 5.

22. 2.50 can be written as 2.500.

Correct Answer: True

23. The decimal 0.006 has 6 in the thousandths place.

Correct Answer: True

24. 6.07 is smaller than 6.007.

Correct Answer: False. 6.07 = 6.070, which is greater than 6.007.

25. 0.5 is equal to 5/100.

Correct Answer: False. 0.5 = 5/10 = 50/100.
