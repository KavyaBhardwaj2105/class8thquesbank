Section A — Multiple Choice Questions (15)

Q1. If x + 8 = 17, what is the value of x?

Correct Answer: 9, because x = 17 − 8.

Q2. Which equation represents the statement “5 more than a number is 21”?

Correct Answer: x + 5 = 21.

Q3. If 4y = 36, then y equals:

Correct Answer: 9, because 36 ÷ 4 = 9.

Q4. If a − 13 = 5, what is a?

Correct Answer: 18, because 18 − 13 = 5.

Q5. Which number makes 3x + 2 = 20 true?

Correct Answer: 6, since 3(6) + 2 = 20.

Q6. A number multiplied by 7 gives 63. What is the number?

Correct Answer: 9.

Q7. If p/5 = 7, then p is:

Correct Answer: 35, because 35 ÷ 5 = 7.

Q8. Which equation has x = 4 as its solution?

Correct Answer: x + 6 = 10.

Q9. If 2m − 7 = 15, then m equals:

Correct Answer: 11, because 22 − 7 = 15.

Q10. If 5n + 4 = 29, the value of n is:

Correct Answer: 5.

Q11. The perimeter of a square is 36 cm. If its side is x cm, which equation is correct?

Correct Answer: 4x = 36.

Q12. If 7 − z = 2, then z is:

Correct Answer: 5, since 7 − 5 = 2.

Q13. A number increased by 12 becomes 30. The number is:

Correct Answer: 18.

Q14. If 6x = 2x + 20, what is x?

Correct Answer: 5, because 6x − 2x = 20, so 4x = 20.

Q15. Which value of t makes 2t + 9 = 25 true?

Correct Answer: 8.

Section C — Assertion & Reasoning (5)

Choose:
A — Both A and R are true, and R correctly explains A.
B — Both A and R are true, but R does not explain A.
C — A is true, but R is false.
D — A is false, but R is true.

Q26. Assertion (A): If x + 6 = 14, then x = 8.
Reason (R): Subtracting 6 from both sides keeps the equation balanced.

Correct Answer: A.

Q27. Assertion (A): The solution of 4x = 28 is x = 6.
Reason (R): Dividing both sides by the same non-zero number preserves equality.

Correct Answer: D. The assertion is false because x = 7, while the reason is true.

Q28. Assertion (A): If y − 5 = 12, then y = 17.
Reason (R): Adding 5 to both sides removes the subtraction of 5.

Correct Answer: A.

Q29. Assertion (A): If 3x + 4 = 19, then x = 5.
Reason (R): After subtracting 4 from both sides, we get 3x = 15.

Correct Answer: A.

Q30. Assertion (A): If 2p = 18, then p = 7.

Correct Answer: D. The correct value is p = 9.

Section G — HOTS / Application Based Questions (10)

Q46. A number is multiplied by 4 and then 6 is added. The result is 34. Find the number.

Correct Answer: 7. Equation: 4x + 6 = 34 → 4x = 28 → x = 7.

Q47. The sum of three consecutive integers is 72. What is the middle integer?

Correct Answer: 24. The integers are 23, 24 and 25.

Q48. A rectangle has length 3 cm more than its width. Its perimeter is 30 cm. What is its width?

Correct Answer: 6 cm. If width = x, length = x+3. 2(x+x+3)=30 → 4x+6=30 → x=6.

Q49. Riya has some pencils. After receiving 8 more pencils, she has 23. How many pencils did she have initially?

Correct Answer: 15. x + 8 = 23.

Q50. A number is decreased by 9 and the result is 17. If the same number is doubled, what is the new result?

Correct Answer: 52. Original number = 26 because 26−9=17. Double = 52.

Q51. The perimeter of an equilateral triangle is 45 cm. A side is represented by x. Which value of x is correct?

Correct Answer: 15 cm, since 3x = 45.

Q52. A student's score was increased by 12 points and became 50. If the original score is represented by s, which statement is correct?

Correct Answer: s + 12 = 50, giving s = 38.

Q53. Two numbers differ by 7. Their sum is 31. What is the smaller number?

Correct Answer: 12. The numbers are 12 and 19; their difference is 7 and sum is 31.

Q54. A student solves 5x − 3 = 27 and writes x = 4. Is the answer correct?

Correct Answer: No, x = 6. 5x−3=27 → 5x=30 → x=6.

Q55. A two-digit number has a tens digit that is 3 more than its units digit. The sum of its digits is 11. What is the number?

Correct Answer: 74. Let units digit = x; tens digit = x+3. Then x+(x+3)=11 → 2x=8 → x=4, so tens digit = 7.
