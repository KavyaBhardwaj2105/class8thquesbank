Section A — Multiple Choice Questions (15)

1. A population is recorded as 7,08,45,019. What is the place value of the digit 8?

Correct Answer: 8,00,000
The digit 8 is in the lakh place.

2. Which is the greatest number that can be formed using the digits 4, 0, 8, 2, 7 and 5 exactly once?

Correct Answer: 8,75,420
Arrange the non-zero digits in descending order and place 0 last.

3. Which number is represented by 6 × 10⁷ + 4 × 10⁵ + 9 × 10³ + 2 × 10² + 8?

Correct Answer: 60,40,09,208
Each power of 10 determines the corresponding place value.

4. A city has 4,96,87,321 residents. Rounded to the nearest lakh, its population is:

Correct Answer: 4,97,00,000
The ten-thousands digit is 8, so the lakh digit is increased by 1.

5. Which statement about 9,99,99,999 is correct?

Correct Answer: It is one less than 10,00,00,000.

6. Which of the following is the correct Indian-system representation of 305,070,604?

Correct Answer: 30,50,70,604

7. The difference between 5,00,00,000 and 4,76,54,321 is:

Correct Answer: 23,45,679

8. A machine produces 2,40,000 items each month. Approximately how many items will it produce in 5 years?

Correct Answer: 1,44,00,000
5 years = 60 months; 2,40,000 × 60 = 1,44,00,000.

9. Which number is closest to 7,49,80,000 when rounded to the nearest crore?

Correct Answer: 7,00,00,000
7,49,80,000 is below the midpoint 7,50,00,000, so it rounds to 7 crore.

10. If 1 crore = 100 lakh, then 6.5 crore equals:

Correct Answer: 650 lakh

11. Which is the smallest number that becomes 5,00,00,000 when rounded to the nearest crore?

Correct Answer: 4,50,00,000

12. A number has 8 in the crore place, 3 in the lakh place, 5 in the thousands place and 7 in the ones place. Which number is it?

Correct Answer: 8,03,05,007

13. A library has 12,48,650 books. It receives 2,75,425 more books. What is the new total?

Correct Answer: 15,24,075

14. Which number has exactly four digits greater than 5?

Correct Answer: 76,843

15. The estimated value of 3,98,76,450 + 2,02,14,800 to the nearest crore is:

Correct Answer: 6 crore
The exact sum is 6,00,91,250, which rounds to 6 crore.

Correct Answer: True

Correct Answer: False

Correct Answer: True

19. The number 7,05,04,009 contains a zero in the ten-thousands place.

Correct Answer: False

20. 4,99,99,999 rounded to the nearest crore is 5,00,00,000.

Correct Answer: True

21. The greatest 7-digit number is 99,99,999.

Correct Answer: True

22. 2,50,00,000 is equal to 25 million.

Correct Answer: True

23. In the Indian system, commas are placed after every three digits from the right.

Correct Answer: False
The first comma is after three digits; thereafter commas occur after every two digits.

24. The number immediately following 9,99,999 is 10,00,000.

Correct Answer: True

25. 5 crore is the same as 500 lakh.

Correct Answer: True

Correct Order: 9 – 6 – 4 – 1 – 0

42. Arrange these quantities from smallest to largest: 4 million, 35 lakh, 3 crore, 42 lakh.

Correct Order: 35 lakh → 4 million → 42 lakh → 3 crore

43. Select the correct digit arrangement for the number 7,04,09,015.

Correct Arrangement: 7 crore + 4 lakh + 9 thousand + 15

44. Arrange the following numbers from greatest to smallest: 8,45,000; 84,50,000; 8,54,000; 85,40,000.

Correct Order: 85,40,000 → 84,50,000 → 8,54,000 → 8,45,000

45. Select the correct place-value decomposition of 5,07,03,204.

Section G — HOTS / Higher Order Thinking Skills (10)

46. A number is greater than 4 crore but less than 4,10,00,000. Its lakh digit is 7. Which could be the number?

Correct Answer: 4,07,85,321

47. A school claims that 48,76,500 is approximately 50 lakh. Another student says it is approximately 49 lakh. Who is correct when rounding to the nearest lakh?

Correct Answer: Student only
48,76,500 rounds to 49,00,000, not 50,00,000.

48. The population of Town A is 3,98,75,600 and Town B is 4,02,10,400. Without exact subtraction, approximately how much larger is Town B?

Correct Answer: About 3.5 lakh

49. A number has 8 digits. Its first digit is 3 and its last digit is 9. What is the greatest possible number if the remaining digits are all 7?

Correct Answer: 3,77,77,779

50. A company reports sales of 2,48,76,450 units. For a presentation it reports the figure as 2.5 crore. Is this a reasonable approximation?

Correct Answer: Yes, because it is close to 2.5 crore.

51. Two numbers have the same first four digits: 7, 4, 2, 6. The fifth digit of Number A is 8 and that of Number B is 3. Which statement must be true?

Correct Answer: Number A is greater than Number B.

52. A number is rounded to the nearest crore and becomes 12 crore. Which interval contains all possible original whole numbers?

Correct Answer: 11,50,00,000 to 12,49,99,999

53. A number is formed by adding 6 crore, 14 lakh, 8 thousand and 52. Which digit will occupy the ten-thousands place?

Correct Answer: 4
14 lakh = 14,00,000, so the ten-lakh digit is 1 and lakh digit is 4; the ten-thousands place is 0 actually.

54. A school wants to display its total annual attendance of 7,96,48,250 as a whole number of crores. What should it display after rounding?

Correct Answer: 8 crore

55. A number is written as 9,00,00,000 − 1,25,001. Which is its standard Indian-system form?

Correct Answer: 8,98,74,999
